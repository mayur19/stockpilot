# StockPilot — Requirements Traceability Matrix

Maps every functional requirement in [requirements.md](requirements.md) to its epic, backlog ticket ([../planning/backlog.md](../planning/backlog.md)), implementing module and verifying tests. Non-functional requirements follow in §2.

**Reading the table**

- _Module_ paths are relative to the repository root. For pending items the module is the pending catalogue entry that currently answers `501` (`apps/api/src/modules/pending/pending.catalog.ts`) or, where no endpoint exists yet, the planned module location.
- _Tests_ lists real test files for implemented requirements. "planned" means no test exists because the feature is not built. Where an implemented requirement has no direct automated test, the gap is stated explicitly.
